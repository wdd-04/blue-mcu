# Blue-MCU 蓝桥杯单片机练习仓库

基于 **STC15F2K60S2** 单片机的蓝桥杯设计与开发项目练习仓库，包含外设模块驱动、历年真题练习和工程模板。

## 硬件平台

- **主控芯片**: STC15F2K60S2（增强型 8051，1T 架构）
- **开发平台**: 蓝桥杯 4T 平台
- **主频**: 12.000MHz
- **开发环境**: Keil C51

## 目录结构
```
blue-mcu/
├── module/ # 外设模块练习
│ ├── 0.BSP/ # 板级支持包（基础工程模板）
│ ├── 1.DS1302/ # DS1302 实时时钟
│ ├── 2.DS18B20/ # DS18B20 温度传感器（单总线）
│ ├── 3.AD-DA/ # AD/DA 模数 / 数模转换

│ ├── 5.normal/ # 基础外设（LED、按键、数码管等）
│ ├── 6.UART/ # 串口通信
│ └── 大模板练习 / # 综合大模板练习
├── exam/ # 历年真题 / 赛题练习
│ ├── 09/ 09-2/ 10/ 11/ 12/ 13/ 14/ 15/ 15-2/
└── V4T/ # V4T 工程模板（米醋电子工作室）
├── Driver/ # 底层驱动
├── User/ # 用户代码
├── main.c # 主程序
├── Init.c/h # 系统初始化
├── Led.c/h # LED 驱动
├── Key.c/h # 按键驱动
├── Seg.c/h # 数码管驱动
```

## 已实现外设模块

| 模块 | 说明 | 通信方式 |
|------|------|----------|
| LED | 指示灯控制 | GPIO |
| KEY | 独立按键/矩阵按键 | GPIO |
| SEG | 八位数码管动态显示 | GPIO 扫描 |
| UART | 串口收发 | UART |
| DS1302 | 实时时钟 | 三线 SPI |
| DS18B20 | 温度采集 | 单总线 OneWire |
| AD/DA | 模数/数模转换 | - |
| EEPROM | 数据掉电存储 | I2C |

## V4T 模板说明

V4T 版本为 V2 版本的改进版，针对 4T 平台做了专项优化，修复了此前版本的若干 Bug。

- **版权**: 米醋电子工作室 (C) 2025
- **架构**: 分层设计（Driver 底层驱动 + User 业务逻辑）
- **特点**: 按键消抖、数码管动态扫描、串口接收缓冲区均已封装，可直接在此基础上开发赛题

## 使用方法

1. 使用 Keil C51 打开对应模块或真题工程
2. 编译生成 `.hex` 文件
3. 通过 STC-ISP 烧录到 STC15F2K60S2 开发板
4. 观察运行结果

## 注意事项

- 部分源码文件以 `.txt` 后缀提供，使用时请改回 `.c` / `.h`
- 延时函数基于 12MHz 主频编写，更换晶振时需重新调整
- 真题目录编号对应不同年份/场次的赛题
